# 邮智汇使用说明

实训 Demo：轮询邮箱，用 DeepSeek 解析邮件，到点生成客户汇总，并通过钉钉推送。图片和扫描版 PDF 用本地 PaddleOCR 提取文字。AI 结果只作辅助，发送或执行前请人工复核。

## 1. 环境

换电脑时，把整个 `youzhihui` 文件夹拷走。新电脑安装 64 位 Python 3.9 或 3.10 后，只双击 `启动.bat`。缺的 Python 包会从 `wheels` 自动装上，已经装好且版本一致的会跳过，不用再从网上下载 Paddle、模型和 poppler。

## 2. 配置

DeepSeek 地址、模型和密钥已经写在 `.env`。双击 `启动.bat` 后会打开浏览器里的演示界面，在页面上填写邮箱、授权码和钉钉，点保存后直接开始。换人时在同一页改完再保存。

- 填入邮箱后自动识别服务器，不用手选企业邮箱或个人邮箱
- `MAIL_PASSWORD` 填授权码，不是网页登录密码
- 钉钉可以先留空，这时不发钉钉通知
- 机器人开了加签或关键词时，再手动填 `DINGTALK_SECRET`、`DINGTALK_KEYWORD`

常见公共邮箱按域名识别。企业自定义域名会查 MX，例如阿里企业邮、腾讯企业邮、Microsoft 365。识别不到时按 `imap.域名` 尝试。

邮件存在本地 SQLite，一封一行，同一封不会重复插入。正文留在库里，页面只显示摘要。收取按批进行，默认每批 20 封；这一批扫完后，如果还有未读，再扫下一批。解析后标成有用、普通或垃圾；垃圾邮件不进入客户汇总和每日总结。

`AUTO_REPLY` 默认 `auto`：只有客户后续操作里出现“回复邮件”这类要求时才写成草稿，在页面上确认后才发出。`always` 是汇总后都准备草稿，`never` 是只生成、不准备回信。

`.env` 已在 `.gitignore` 中。不要把这个文件提交或转发。密钥一旦出现在聊天记录里，建议到 DeepSeek 控制台作废并更换，然后只改本地 `.env`。

## 3. poppler 和 OCR 模型

poppler 26.09.0 已解压到 `tools/poppler`，路径写成相对目录，换电脑不用改。

OCR 检测和识别模型已下载到 `tools/paddlex`。当前项目路径包含中文，Paddle 无法直接读取，程序会在 `%LOCALAPPDATA%\youzhihui\paddlex` 建立一个指向该目录的联接。

## 4. 启动

只双击 `启动.bat`。检查依赖和启动都在后台进行，不会留下黑窗口；只有安装失败时才会弹出窗口说明原因。浏览器打开演示界面。左侧填写邮箱，工作台看收件和客户任务，运行记录按天查看。再双击一次不会另开一份，只会重新打开页面。

新邮箱第一次接入，只读取最近 40 封，不改邮箱里的未读状态。更早的已读信不拉取。之后按批收取未读，默认每批 20 封，可以在调度对话里改成 5 到 40 封。这一批扫完后，如果还有未读，再扫下一批，入库成功后才在邮箱里标成已读。识别 PDF 附件时不再弹出黑窗口。没改过规则时，之后每 5 分钟再看有没有新邮件。客户要求回复时，等到汇总正文生成后才写成草稿，确认后再发；没有正文的不放进可发送草稿。每天 21:00 按邮件原日期推送当天总结，并单独列出被排除的垃圾主题，以及当天新入库、日期更早的信。客户任务默认每 60 秒检查一次。调度对话里可以说明何时拉取、何时发送，页面会先给出将要执行的规则，确认后才保存。停止时点左下角「退出程序」。数据在 `data/youzhihui.db`。

## 5. 怎样触发客户汇总

给这个邮箱发一封未读邮件，正文写清客户、时间和范围，例如：

```text
客户名称：华东零售
请于今天 18:30 汇总近 7 天关于对账的邮件，按条列示，完成后回复本邮箱。
```

程序会把执行时间收成 `YYYY-MM-DD HH:MM:SS`。信里的「今天」「明天」按这封信原来的日期计算。写“立即汇总”会马上排队。时间无法识别，或算出来已经过去，任务状态是 `need_time`，不会自动执行。

汇总只看收到这封信的那个邮箱，检索最近 `SUMMARY_LOOKBACK_DAYS` 天、最多 30 封非垃圾邮件。超过 30 封时，结果里会写明只看了最近 30 封。任务失败后状态为 `failed`，在页面上点「再试一次」并确认，就会重新排队。
